# Cold cloud survival in turbulent boxes

Simulations and analysis from my internship at MPA (2025)

My contributions are in `runs/`, `analysis/` and `figures/`. The simulation setup is from [Das et al. 2024](https://ui.adsabs.harvard.edu/abs/2024MNRAS.527..991D), built on [Athena++](https://github.com/PrincetonUniversity/athena).
